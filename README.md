# Weather App

A weather application built using **React.js**, **Tailwind CSS**, and the **Visual Crossing API**. It provides users with detailed weather forecasts and historical weather data in a responsive and user-friendly interface.

---

## Features

- **Today's Forecast**: Current weather conditions at your location.  
- **Tomorrow's Forecast**: Weather predictions for the next day.  
- **Historical Data**: Weather details for yesterday.  
- **15-Day Forecast**: Extended weather outlook for the next 15 days.  
- **Hourly Forecast**: Hour-by-hour weather updates.

---

## Technologies Used

- **React.js**: A JavaScript library for building the user interface.  
- **Tailwind CSS**: A utility-first CSS framework for styling the application.  
- **Visual Crossing API**: A weather data API for fetching real-time and historical weather information.
